# Группа LI. Пределы на дорогое и на размер

Строки: `(?i)limit|rate|throttle|max_|timeout|create_task|BackgroundTasks|send_message|sms|email|retry|semaphore|queue`
Пути: —

### LI-1. Дорогое действие без предела
Проверка: агент
Признак: вызов модели, рассылка, сообщение в чужую систему, письмо, SMS, тяжёлый отчёт запускаются запросом
без счётчика на клиента или учётку.
Не ошибка: предел по клиенту и времени; действие только для доверенной роли и с подтверждением.
Как закрыть: счётчик по клиенту с окном времени.
Класс: 9

### LI-2. Предел общий на всех и запирает своих
Проверка: агент
Признак: один счётчик на весь сервис; при его срабатывании отказ получают и владелец, и живые клиенты.
Счётчик отказов без окна времени копится вечно.
Не ошибка: счётчик по паре «кто + что», окно времени, у владельца есть обход.
Как закрыть: счётчик по паре, окно, сброс.
Класс: 9

### LI-3. Нет предела размера входа
Проверка: агент
Признак: тело запроса, сообщение, имя, файл, список без предела длины или числа элементов.
Не ошибка: `max_length` в модели, предел тела на сервере.
Как закрыть: пределы в модели и на сервере.
Класс: 9

### LI-4. Исходящий запрос без срока ожидания
Проверка: скрипт Ruff S113 — для `requests`; агент — для `httpx` и `aiohttp`
Признак: запрос к чужой системе без `timeout`; зависший ответ держит поток или очередь.
Не ошибка: срок задан у клиента целиком.
Как закрыть: `timeout` у клиента.
Класс: 9

### LI-5. Фоновая работа без ограничения числа
Проверка: агент
Признак: `create_task`, фоновая задача, очередь на каждый запрос; повторный запуск того же не проверяется.
Не ошибка: проверка «уже идёт», предел одновременных.
Как закрыть: отказ, если та же работа уже идёт; предел одновременных.
Класс: 9

### LI-6. Общая очередь: поток одного клиента задерживает остальных
Проверка: агент
Признак: запросы всех клиентов и операторов идут в чужую систему через одну очередь с общим пределом.
Не ошибка: у каждого клиента свой предел, служебные ответы — отдельной очередью.
Как закрыть: предел на клиента до общей очереди.
Класс: 9
