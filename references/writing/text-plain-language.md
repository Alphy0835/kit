# Простой язык: стандарт и государственные руководства

Открывай, когда пишешь для широкого читателя: страницу сайта, письмо заказчику, справку, объяснение. Для
инструкций и описаний работы системы правила строже: `text-ste100.md`.

## Содержание

1. Четыре принципа стандарта
2. Числа из государственных руководств
3. Правила, общие для всех руководств
4. Слова требований
5. Где руководства расходятся

## 1. Четыре принципа стандарта

ISO 24495-1:2023 — международный стандарт простого языка. В нём четыре принципа и 18 указаний под ними.
Чисел в стандарте нет: их задают руководства стран.

| Принцип | Вопрос | Указания |
|---|---|---|
| Уместность | Получает ли читатель то, что ему нужно | Определить читателя, цель чтения, обстановку чтения, вид документа, нужное содержание |
| Находимость | Легко ли найти нужное | Строение под читателя, заголовки, по которым видно, что дальше, дополнительное — отдельно |
| Понятность | Легко ли понять найденное | Привычные слова, ясные и краткие предложения и абзацы, уважительный тон, связность |
| Применимость | Может ли читатель действовать | Проверка при разработке, проверка на читателях, наблюдение за использованием |

Порядок принципов — порядок работы: сначала читатель и содержание, потом строение, потом слова, потом
проверка.

## 3. Правила, общие для всех руководств

- Текст пишется для названного читателя.
- Главное стоит в начале. Общее идёт раньше исключений.
- Документ построен вокруг вопросов читателя.
- Процесс описан в порядке времени.
- Предложение выражает одну мысль.
- Абзац — одна тема, начинается с главной фразы.
- Залог действительный. Время настоящее.
- Действие названо глаголом, а не существительным: «проверить», а не «провести проверку».
- Привычное слово вместо книжного: «если», а не «в случае если»; «чтобы», а не «в целях».
- Сокращение расшифровано при первом упоминании.
- Заголовки одного уровня одного вида.
- Сносок нет.
- Прописными буквами и подчёркиванием текст не выделяется: подчёркнутое принимают за ссылку.
- Документ проверяют на читателе: просят пересказать либо выполнить задачу по тексту.

## 4. Слова требований

В документе, где есть требования, слова обязательности значат одно и то же от начала до конца.

Образец из британского руководства:

| Слово | Значение |
|---|---|
| «должен» | Требование закона |
| «нужно» | Обязательный шаг без последствий по закону |
| «можно» | Действие по желанию |

Образец из RFC 2119 и RFC 8174, для технических норм:

| Слово | Значение |
|---|---|
| ДОЛЖЕН, НЕ ДОЛЖЕН | Требование или запрет без исключений |
| СЛЕДУЕТ, НЕ СЛЕДУЕТ | Отступить можно по веской причине, последствия надо взвесить |
| МОЖЕТ | Действительно по желанию |

Правила RFC:

- Слово имеет заданный смысл только заглавными буквами. Строчное «должен» — обычная речь.
- В начале документа стоит абзац о том, как понимать эти слова.
- Слова применяются скупо: только там, где без них система не сработает или будет вред.

Русской стандартной формулы для этих слов нет. Она задаётся в самом документе. Перевод слов — наш.

## 5. Где руководства расходятся

| Вопрос | Стороны |
|---|---|
| Заголовок-вопрос | Великобритания запрещает. США считают удачным |
| Длина предложения | 25 слов как повод проверить, 15–20 как цель, 20 в среднем |
| Длина абзаца | До 3, до 5 или от 3 до 8 предложений |
| Название с экрана | Великобритания: жирным в инструкции, в кавычках в остальном тексте |
| «Нажмите» или «выберите» | Великобритания: «выберите», потому что читатель может работать без мыши |
