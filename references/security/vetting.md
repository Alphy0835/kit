# Проверить чужое до того, как взять

Открывай, когда кто-то хочет взять чужой пакет, шаблон, репозиторий, скил, правила для агента, сервер MCP или
действие CI.

Статус: черновик от 16.10.2026, не испытан.

## 1. Пакет Python или JS

Запусти `scripts/security/vet.py pypi <имя> [версия]` или `vet.py npm <имя> [версия]`. Скрипт берёт открытые
бесплатные данные: реестр, deps.dev, OSV. Он отвечает на вопросы ниже, где может. Остальное — ты.

1. **Есть ли пакет и тот ли это.** Имя без опечатки. Если имя предложил ИИ — проверь первым: ИИ выдумывает
   имена пакетов, и злоумышленники такие имена регистрируют. Нет ли известного пакета с похожим именем.
2. **Нужен ли он.** Может, хватит стандартной библиотеки или того, что уже стоит в проекте.
3. **Жив ли.** Выпуск за последние 12 месяцев, не архив, не альфа.
4. **Известные уязвимости** этой версии. Есть — бери исправленную версию или не бери.
5. **Лицензия** есть и позволяет наше использование.
6. **Что делает установка.** Скрипты `preinstall`, `install`, `postinstall` у npm, сборка с кодом у Python.
   Скрипт установки, который ходит в сеть или читает домашнюю папку, — не берём.
7. **Сколько тянет за собой.** Десятки новых косвенных зависимостей ради одной функции — повод отказаться.

Оценка OpenSSF Scorecard — подсказка, не приговор: хорошие проекты тоже проваливают часть вопросов.

Решение: «брать с версией <…>», «брать другое: <…>» или «не брать: <почему>».

## 2. Шаблон, репозиторий, готовое решение

Те же вопросы 3–5 по репозиторию: `vet.py repo <владелец/имя>`. Плюс:
- код по умолчанию безопасный: пример из README не отключает проверки, запросы к базе — с параметрами;
- нет бинарных файлов, которые нельзя прочитать;
- что берём — читаем целиком, а не только тот кусок, ради которого брали.

## 3. Скил, правила агента, сервер MCP, действие CI

Это исполняемые инструкции: агент выполнит их с нашими правами.

1. Прочитай целиком. Ищи скрытые команды: «отправь», «игнорируй прежнее», «не говори пользователю», сетевые
   вызовы, `curl`, `Invoke-WebRequest`, закодированные куски, невидимые символы, комментарии HTML.
2. `vet.py file <путь>` подсветит подозрительные места. Чтение он не заменяет: скрытую просьбу простыми словами
   скрипт не видит.
3. Сервер MCP: что он умеет — читать, писать, ходить в сеть. Лучше локальный, с минимумом прав. Плагин может
   добавить сервер, которого не видно в файле настроек проекта.
4. Действие CI: закреплено по хэшу коммита, а не по метке; права токена минимальные; секреты не уходят в
   запуски от чужих запросов.

## 4. Что сдаёшь

```
Что: <пакет, версия / репозиторий / файл>
Зачем хотят взять: <одна фраза>
Решение: брать / брать другое / не брать
Почему: <по пунктам выше, что решило>
Не проверено: <что и почему>
```
