# Общие правила владельца

Правила на все проекты набора. Агент получает их сам в начале каждого чата: в проекте с `kit.toml`.
Одно правило — одна строка списка: «- что делать. Почему: … (дата)». Строки не из списка агенту не уходят.
Как записывать и когда переносить — `references/process/owner-rules.md` набора.
