# База типовых проверок

Открывай, когда ведёшь проверку (`references/security/lead.md`, раздел 3а) или обновляешь базу
(`references/security/update-base.md`).

Статус: черновик от 17.10.2026, не испытан.

## Что это

Список типовых ошибок безопасности, которые бывают в любом веб-продукте: собранный из строки запрос к базе,
пароль без хэша, маршрут без проверки права. Каждая ошибка — запись. Записи разложены по группам, одна группа —
один файл.

База — страховка. На нашей истории типовые ошибки почти не встречались: дыры были в логике доступа. Поэтому
база должна стоить почти ноль: всё, что ловит шаблон, ловит программа, а агент смотрит только то, что
шаблоном не записать.

## Как запись проверяется

У каждой записи поле «Проверка»:
- **скрипт** — шаблон из `scripts/security/scan.py` (правило Ruff, сканер секретов, OSV-Scanner, Hadolint). Агент
  её не повторяет, он читает вывод скрипта.
- **агент** — проверяющий на Haiku по роли `references/security/checker.md`. Одна группа — один проверяющий.
- **стенд** — только запуском. В базе для полноты, проверяет охотник или человек.

## Как выбираются группы

`scripts/security/checks.py` смотрит изменённые файлы и строки правки и называет группы, которые правка задела.
Две строки в начале файла группы — его вход: `Строки:` — регулярное выражение по добавленным строкам,
`Пути:` — шаблоны путей изменённых файлов через пробел (`—`, если нет). Новую группу скрипт подхватывает сам,
код править не нужно.

## Формат записи

```
### <КОД>-<номер>. <что не так, одной строкой>
Проверка: скрипт <правило> | агент | стенд
Признак: <что видно в коде>
Не ошибка: <когда так можно>
Как закрыть: <что сделать>
Класс: <номер из classes.md>
```

Записи пишутся своими словами. Чужие списки правил целиком не копируются: у них свои лицензии.

## Группы

- `input.md` — данные снаружи попадают в запрос к базе, команду, путь к файлу, адрес запроса.
- `auth.md` — вход, пароли, сессии, токены.
- `access.md` — права маршрута, чужой объект, лишние поля.
- `exposure.md` — секреты и данные наружу: журнал, ошибки, ответы, настройки.
- `browser.md` — вывод в страницу, куки, CORS, запросы с чужого сайта.
- `ai.md` — вызов модели, база знаний, инструменты агента.
- `limits.md` — пределы на дорогое и на размер.
- `files.md` — загрузка и чтение файлов.
- `deploy.md` — Docker, настройки запуска, зависимости.
