# kit

Набор ролей команды разработки для Claude Code: тим лид, продакт, дизайнер, бекенд, фронтенд, тестировщик,
безопасник и секретарь встреч. Каждая роль — скил со справками и скриптами проверки.

## Установка

```
claude plugin marketplace add Alphy0835/kit
claude plugin install kit@alphy0835
```

Роль вызывается командой `/kit:<роль> <задача>`, например `/kit:backend CB_TASK_001`.
Настройка проекта — `assets/kit.example.toml` и `references/process/setup.md`.

## Что где

- `skills/` — скилы ролей.
- `references/` — справки, которые скил открывает по шагу.
- `scripts/` — проверки без ИИ: учёт задач, тесты, рабочая копия задачи, безопасность.
- `hooks/` — хуки: сверка модели и заведение рабочей копии на команде исполнителя.
- `assets/` — шаблоны задания, отчёта, решения, карты доступов, `kit.toml`.
- `docs/` — как набор собирался: источники, исследования, замеры.
