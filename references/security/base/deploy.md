# Группа DE. Docker, настройки запуска, зависимости

Строки: `(?i)uvicorn\.run|host\s*=|0\.0\.0\.0|verify\s*=\s*False|ssl|debug|reload\s*=\s*True`
Пути: `Dockerfile* *.dockerfile docker-compose*.yml compose*.yml *requirements*.txt package.json package-lock.json *.lock .github/workflows/*`

### DE-1. Уязвимая или незакреплённая зависимость
Проверка: скрипт OSV-Scanner
Признак: версия с известной уязвимостью; версия не закреплена (`>=` без верхней границы в файле, который ставит
продукт).
Не ошибка: зависимость только для разработки и не попадает в образ.
Как закрыть: закреплённая версия с исправлением.
Класс: 11

### DE-2. Контейнер от root, с сокетом Docker, с лишними правами
Проверка: скрипт Hadolint — частично; агент
Признак: нет `USER`, проброшен `/var/run/docker.sock`, `privileged: true`, `network_mode: host`.
Не ошибка: служебный контейнер, которому это нужно по замыслу, и это записано.
Как закрыть: свой пользователь, без сокета, без лишних прав.
Класс: 11

### DE-3. Порт открыт наружу без нужды
Проверка: скрипт Ruff S104 — для кода; агент — для compose
Признак: `ports: "8000:8000"` или `0.0.0.0` у сервиса, который должен быть доступен только через прокси.
Не ошибка: `127.0.0.1:8000:8000`; сервис публичный по замыслу.
Как закрыть: привязка к `127.0.0.1`, наружу — только прокси.
Класс: 11

### DE-4. Секрет в образе или в рецепте сборки
Проверка: скрипт — сканер секретов; агент — для `ARG`, `ENV`, `COPY .env`
Признак: `.env` копируется в образ; секрет в `ENV` или `ARG`; секрет печатается в журнале сборки.
Не ошибка: секрет приходит при запуске из окружения сервера.
Как закрыть: `.dockerignore`, секреты при запуске.
Класс: 4, 11

### DE-5. Проверка сертификата выключена
Проверка: скрипт Ruff S501; агент — для `httpx` и `aiohttp`
Признак: `verify=False`, `ssl=False`.
Не ошибка: только на стенде и включается переменной.
Как закрыть: проверка включена.
Класс: 11

### DE-6. Рецепт выкладки запускается от чужого кода
Проверка: агент
Признак: процесс CI с секретами запускается на запрос из чужой ветки; шаг вставляет текст из запроса в
команду оболочки.
Не ошибка: секреты только для запуска владельцем.
Как закрыть: запуск командой владельца, текст запроса — через переменную окружения, а не в строке команды.
Класс: 11
