Источники справок `references/security/` и `references/code/security.md`. В самих справках их нет: справку
читает агент в работе. Здесь — для того, кто правит набор. Сводка со всеми входами —
`docs/security-synthesis.md`, подборки — `docs/research/security/`.

(`ai-practice.md`), И — история «Рабочей» (сводка, раздел «Входы»), С — слово владельца.

## Скрипты `scripts/security/`

- `triggers.py`: поводы — сводка, вывод 1. Замер 16.10.2026 на копии «Рабочей», 120 последних слияний задач: из
  96 с кодом поводы у 64. Поводы есть у всех пяти найденных слияний, где дыра из И-2 была в коде (CN_TASK_037,
  CN_TASK_074, CB_TASK_190, CB_TASK_216, CB_TASK_108). KB_TASK_047 повода не даёт и не должен: секрет там вывел
  в чат исполнитель командой, код ни при чём. Первая версия звала на 72 из 120. Шум давали импорты JS с `../`,
  `.env.example`, документы о выкладке, слово `role` в истории чата — убраны.
- `scan.py`: OSV-Scanner для `requirements.txt` сам вычисляет косвенные пакеты (вид источника не «lockfile»).
  Их версия — догадка сканера, поэтому помечена. На копии «Рабочей» 16.10: python-dotenv 1.0.1 прописан прямо,
  CVE-2026-28684; anyio 4.9.0, aiohttp 3.9.5, idna 3.9.0 — косвенные.
- `vet.py`: открытые API без ключей — PyPI JSON, npm registry, deps.dev v3, OSV v1, GitHub REST.
