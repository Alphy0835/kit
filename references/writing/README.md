# База справочников: как писать документацию

Указатель. По нему скил выбирает, какие файлы открыть под задачу. Остальные файлы не открываются.

Порядок работы:

1. Найди в таблице строку с тем, что пишешь.
2. Открой файл из колонки «Строение» и файл из колонки «Текст». Обычно это два файла.
3. Вид документа не назван — сначала `doc-types.md`.
4. Заказчик просит «по ГОСТу» — вместо `text-ste100.md` открой `text-gost.md`.
5. Проверяешь готовый текст, а не пишешь — открой `check-text.md` и раздел `check-docs.md` под вид документа.

## Правила самой базы

- Файл открывается первой строкой «Открывай, когда…». По ней видно, нужен ли он.
- В конце файла — таблица источников с пометкой, что прочитано, а что известно по пересказу.
- Образец документа — шаблон: строение и места для своего текста в угловых скобках `<…>`. Готового текста о
  каком-то продукте в образце нет. Так велел владелец 14.10.2026: образец должен подходить к любому проекту.
- Пример «было — стало» показывает одну фразу, а не документ. Он свой, вымышленный. Систем заказчика в нём нет.
- Строка с пометкой «предложение тим лида» — не правило, пока владелец её не утвердил.
- Тексты стандартов не копируются: правила пересказаны своими словами.
- Новое правило попадает в файл, а его источник или случай из своей работы — в `docs/basis/writing.md`.
