# Группа AU. Вход, пароли, сессии, токены

Строки: `(?i)password|passwd|login|logout|session|cookie|token|jwt|bcrypt|argon2|pbkdf2|hashlib|otp|reset|compare_digest|secrets\.`
Пути: `*auth* *login* *session*`

### AU-1. Пароль хранится не тем хэшем
Проверка: скрипт Ruff S324 — для md5 и sha1; агент — для остального
Признак: пароль хэшируется `sha256`, `md5`, без соли, или хранится как есть.
Не ошибка: Argon2id, scrypt, bcrypt, PBKDF2 с большим числом повторов.
Как закрыть: Argon2id через проверенную библиотеку, проверка — её функцией.
Класс: 3

### AU-2. Секрет сравнивается обычным `==`
Проверка: агент
Признак: токен, подпись, код из письма сравниваются `==` или `!=`.
Не ошибка: `hmac.compare_digest` / `secrets.compare_digest`.
Как закрыть: сравнение за постоянное время.
Класс: 3, 5

### AU-3. Токен или код из неслучайного источника
Проверка: скрипт Ruff S311
Признак: `random`, время, номер записи как основа токена сессии, сброса, приглашения.
Не ошибка: `secrets.token_urlsafe`, `uuid4` для того, что не секрет.
Как закрыть: `secrets`.
Класс: 3

### AU-4. Сессия живёт после смены пароля, выхода, отключения учётки
Проверка: агент
Признак: выход удаляет куку, но запись сессии на сервере остаётся; смена пароля и отключение учётки не гасят
выданные сессии и токены.
Не ошибка: каждая проверка сессии сверяет её с сервером и с состоянием учётки.
Как закрыть: при выходе, смене пароля, отключении — удалять сессии учётки на сервере.
Класс: 3

### AU-5. Нет предела попыток входа, или предел запирает владельца
Проверка: агент
Признак: вход, проверка кода, сброс пароля без счётчика неудач; или общий счётчик на всех, который закрывает
вход и владельцу; или дорогая проверка пароля идёт и для запертого логина.
Не ошибка: предел по паре «логин + адрес» с окном времени, запертый логин отказывает до проверки пароля,
у владельца есть способ войти.
Как закрыть: счётчик по паре, окно времени, отказ до дорогого хэша.
Класс: 3, 9

### AU-6. Ответ входа выдаёт, есть ли такой логин
Проверка: агент
Признак: разные тексты или коды ответа для «нет логина» и «неверный пароль»; сброс пароля отвечает
«такой почты нет».
Не ошибка: один ответ на оба случая.
Как закрыть: одинаковый ответ и одинаковое время.
Класс: 3

### AU-7. Токен проверяется не целиком
Проверка: агент
Признак: JWT разбирается без проверки подписи, алгоритм берётся из самого токена, нет проверки срока.
Не ошибка: алгоритм задан в коде, срок и подпись проверяются библиотекой.
Как закрыть: явный список алгоритмов, проверка `exp`, ключ из настройки сервера.
Класс: 3

### AU-8. Сессия в адресе или в хранилище браузера
Проверка: агент
Признак: токен сессии в строке адреса, в `localStorage`.
Не ошибка: кука `HttpOnly`; токен в адресе одноразовый и короткоживущий.
Как закрыть: кука `HttpOnly; Secure; SameSite`.
Класс: 3, 4
