## Ролик-анонс проекта одной командой — /brag

Дата: 16.10.2026. Владелец назвал «brag»; репозиторий найден: https://github.com/latent-spaces/brag (16 тыс. звёзд,
MIT, последнее обновление 13.10.2026). Для роли «креатор».

Скил агента: из проекта в папке делает ролик-анонс на 20 секунд с музыкой, движением и текстом для публикации.
В папке `brag-output/` — план, бриф кадров, текст и `brag.mp4`. Классика работает на HyperFrames (HeyGen). Есть
`/brag-slim` под Opus 5.5 — без HyperFrames и без готовых ассетов; на Opus 5.5 включается сам. Ставится плагином
Claude Code (`/plugin marketplace add latent-spaces/brag`). Голос выключен, включается `--voice`. Есть
`--tone` для подачи.

Оговорки: это ролик-анонс про собственный проект, а не монтаж отснятого. Есть платный сайт letsbrag.app, сам скил
бесплатный. На Windows репозиторий держится на символических ссылках: копировать `skills/brag/` руками.

Первый шаг: при сборке креатора — по слову владельца поставить `/brag-slim` и сделать один ролик про проект набора.
Тот же ролик сравнить с Remotion и HyperFrames из подборки выше.

## Монтаж видео агентом — Concat

Дата: 16.10.2026. Ссылка от владельца: https://github.com/jub0t/concat. Для роли «креатор».

Открытый видеоредактор, замена CapCut: Windows, macOS, Linux, Android. Агент управляет им через MCP, CLI,
JSON-RPC и gRPC. Субтитры — локальным Whisper, озвучка и клон голоса, удаление фона, ключевые кадры, экспорт
до 4K 60 кадров. Всё считается на своём компьютере, без аккаунта и подписки.

Оговорки (по README 16.10): бета, версия 0.2.7, 103 открытых задачи; лицензия AGPL-3.0 — для работы
инструментом подходит, свои правки в нём при раздаче пришлось бы открыть; сборки для Windows без подписи —
SmartScreen предупредит.

Первый шаг: при сборке креатора — по слову владельца скачать установщик с GitHub Releases и проверить одну склейку
через MCP.
