# Группа BR. Вывод в страницу, куки, CORS, запрос с чужого сайта

Строки: `innerHTML|outerHTML|insertAdjacentHTML|dangerouslySetInnerHTML|v-html|document\.write|\|\s*safe|Markup\(|autoescape|set_cookie|CORSMiddleware|allow_origins|postMessage|addEventListener\(\s*["']message|target=["']_blank|localStorage|sessionStorage`
Пути: `*.js *.ts *.jsx *.tsx *.vue *.html *.jinja *.j2`

### BR-1. Данные вставляются в страницу как HTML
Проверка: скрипт Ruff S701, S704 — для шаблонов Python; агент — для JS
Признак: `innerHTML`, `insertAdjacentHTML`, `v-html`, `| safe`, `Markup()` с данными из запроса, базы, ответа
модели, имени файла.
Не ошибка: `textContent`, экранирование шаблона включено, HTML проходит через санитайзер со списком тегов.
Как закрыть: вставка как текст; где нужен HTML — проверенный санитайзер.
Класс: 7

### BR-2. Ответ модели или базы знаний выводится как разметка
Проверка: агент
Признак: Markdown ответа ИИ превращается в HTML без очистки; ссылки и картинки из ответа выводятся как есть.
Не ошибка: разбор Markdown с выключенным HTML и проверкой схемы ссылок (`https`, без `javascript:`).
Как закрыть: Markdown без HTML, ссылки только `https`.
Класс: 7, 8

### BR-3. Кука сессии без флагов
Проверка: агент
Признак: `set_cookie` без `httponly`, `secure`, `samesite`.
Не ошибка: кука не несёт сессии или секрета.
Как закрыть: `HttpOnly; Secure; SameSite=Lax` или строже.
Класс: 3

### BR-4. Действие по куке без защиты от запроса с чужого сайта
Проверка: агент
Признак: вход по куке, маршрут меняет данные, нет проверки токена формы, заголовка или `Origin`; `SameSite=None`.
Не ошибка: `SameSite=Lax` или `Strict` и действие не по GET; или проверка `Origin` по списку.
Как закрыть: `SameSite` плюс проверка `Origin` у маршрутов, меняющих данные.
Класс: 2, 3

### BR-5. CORS открыт всем вместе с учётными данными
Проверка: агент
Признак: `allow_origins=["*"]` или источник берётся из запроса как есть, и `allow_credentials=True`.
Не ошибка: список источников в настройке.
Как закрыть: явный список источников.
Класс: 2

### BR-6. Сообщения между окнами без проверки источника
Проверка: агент
Признак: обработчик `message` не сверяет `event.origin`; `postMessage(..., "*")` с данными.
Не ошибка: проверка `origin` по списку, адресат указан явно.
Как закрыть: сверка `origin`, явный адресат.
Класс: 7

### BR-7. Встраивание страницы панели в чужой сайт
Проверка: агент
Признак: у панели нет `frame-ancestors` или `X-Frame-Options`.
Не ошибка: страница встраивается по замыслу (виджет) и не несёт действий под чужой сессией.
Как закрыть: `frame-ancestors` со списком.
Класс: 7
