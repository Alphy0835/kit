# Группа IN. Данные снаружи в запросе, команде, пути, адресе

Строки: `execute|text\(|\.raw\(|subprocess|os\.system|Popen|eval\(|exec\(|pickle|yaml\.load|httpx|requests\.|aiohttp|urlopen|open\(|Path\(|FileResponse|zipfile|tarfile|xml\.|BaseModel|Field\(`
Пути: —

### IN-1. Запрос к базе собран из строки
Проверка: скрипт Ruff S608; агент — там, где строку собирают в одной функции, а выполняют в другой
Признак: f-строка, `%`, `.format()` или `+` внутри текста запроса, и в строку попадает значение из запроса,
события или базы знаний.
Не ошибка: склеиваются только литералы кода; значения идут параметрами `?` / `:name`.
Как закрыть: значения — параметрами запроса. Имя колонки и порядок сортировки — из белого списка в коде.
Класс: 6

### IN-2. Имя колонки, таблицы или порядок сортировки из запроса
Проверка: агент
Признак: параметр `sort`, `order`, `field`, `column` из запроса подставляется в текст SQL.
Не ошибка: значение сверяется со списком допустимых до подстановки.
Как закрыть: словарь «что пришло → что подставить», остальное — отказ.
Класс: 6

### IN-3. Команда ОС из строки
Проверка: скрипт Ruff S602, S605; агент — если аргументы списка берутся из ввода
Признак: `shell=True`, `os.system`, строка команды с подстановкой; или список аргументов, где ввод может стать
ключом программы (начинается с `-`).
Не ошибка: список аргументов из констант; ввод отделён `--`.
Как закрыть: список аргументов без оболочки, ввод — после `--`, проверка формата до вызова.
Класс: 6

### IN-4. Исполнение кода из данных
Проверка: скрипт Ruff S307, S102, S301, S506
Признак: `eval`, `exec`, `pickle.loads`, `yaml.load` без безопасного загрузчика над данными не из кода.
Не ошибка: только данные, которые записал сам код и которые никто снаружи не меняет.
Как закрыть: `json`, `yaml.safe_load`, разбор по схеме.
Класс: 6

### IN-5. Путь к файлу из ввода
Проверка: агент
Признак: имя или путь из запроса, события, вложения склеивается с папкой и открывается.
Не ошибка: путь приводится к полному (`resolve()`) и сверяется, что он внутри разрешённой папки; или имя
задаёт сервер.
Как закрыть: имя задаёт сервер; если нужно имя пользователя — `resolve()` и проверка `is_relative_to(папка)`.
Класс: 10

### IN-6. Адрес исходящего запроса из ввода
Проверка: агент
Признак: HTTP-клиент берёт адрес целиком или хост из запроса, ссылки в чате, поля настройки, ответа чужой
системы.
Не ошибка: адрес собирается кодом из постоянной части и проверенного идентификатора; хост сверяется со списком.
Как закрыть: список разрешённых хостов, только `https`, запрет внутренних адресов, без перехода по
перенаправлениям на другой хост.
Класс: 10

### IN-7. Разбор XML и архивов
Проверка: скрипт Ruff S202, S320; агент — для `zipfile`
Признак: `tarfile.extractall`, `zipfile` без проверки путей внутри архива, разбор XML стандартной библиотекой
с внешними сущностями.
Не ошибка: архив создал сам код.
Как закрыть: проверять путь каждого элемента архива и размер распакованного; `defusedxml`.
Класс: 10

### IN-8. Проверка формата только на клиенте
Проверка: агент
Признак: поле проверяется в JS или в форме, а модель сервера (`pydantic`, схема) его принимает любым.
Не ошибка: сервер проверяет то же: тип, длину, допустимые значения.
Как закрыть: ограничения в модели сервера: `max_length`, `Literal`, диапазоны.
Класс: 2
