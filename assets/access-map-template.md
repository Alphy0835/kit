# Карта доступов

Где взять каждый доступ проекта: ключ, вебхук, токен, учётку, сервер. Значений здесь нет — только имя
переменной и место, где лежит значение. Файл в git, его видят все.

Ведёт тим лид. Новый доступ сначала записывается сюда, потом попадает в задание полем «Доступы».

## <ИМЯ_ПЕРЕМЕННОЙ> — <что даёт, одной строкой>

- Где значение: <файл вне git и имя переменной в нём, например `.env` рабочей копии → `B24_READ_WEBHOOK_URL`;
  или «у владельца — спросить»>
- Как подключить: <откуда код или команда берёт значение, например «переменная окружения, читает
  `app/config.py`»>
- Проверить, что работает: <команда, которая не печатает значение, и что она отвечает>
- Кому: <роли, которым можно>
- Нельзя: <запись, боевые данные, отдельные методы; нет ограничений — «—»>
