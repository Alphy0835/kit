# Группа EX. Секреты и данные наружу

Строки: `(?i)log(?:ger|ging)?\.|print\(|detail\s*=|HTTPException|raise\s|traceback|token|secret|api_?key|password|authorization|bearer|getenv|environ|debug|redact|mask`
Пути: `.env* *settings* *config* *.toml *.yaml *.yml`

### EX-1. Секрет в коде или в коммите
Проверка: скрипт — сканер секретов
Признак: ключ, токен, пароль строкой в коде, в файле примера, в тесте.
Не ошибка: значение-заглушка в файле примера.
Как закрыть: секрет — из окружения; утёкший — заменить, удаление из кода его не спасает.
Класс: 4

### EX-2. Секрет или данные клиента в журнале
Проверка: агент
Признак: в журнал пишется заголовок `Authorization`, адрес с токеном, тело запроса или ответа чужой системы,
текст исключения клиента HTTP, телефон, переписка. Вычистка секретов есть для одного вывода (панель, ответ),
а журнал процесса получает тот же текст без неё. Журналы библиотек HTTP на уровне отладки пишут заголовки.
Не ошибка: перед записью стоит та же вычистка; журнал пишет только номер записи.
Как закрыть: одна функция вычистки для всех выводов: журнал, панель, ответ; уровень журналов библиотек HTTP —
не ниже предупреждений.
Класс: 4

### EX-3. Секрет в адресе запроса
Проверка: агент
Признак: токен в пути или параметре адреса к чужой системе или к своему маршруту. Адреса попадают в журналы
прокси, сервера и библиотек.
Не ошибка: чужая система принимает ключ только в адресе — тогда этот адрес не пишется в журнал.
Как закрыть: ключ в заголовке; если нельзя — вычистка адреса перед журналом.
Класс: 4

### EX-4. Текст ошибки уходит клиенту
Проверка: агент
Признак: `detail=str(e)`, текст исключения, путь файла, запрос SQL, ответ чужой системы в ответе маршрута или
в сообщении бота.
Не ошибка: клиенту — общий текст и номер, подробности — в журнал.
Как закрыть: общий обработчик ошибок, который отдаёт короткий текст.
Класс: 4

### EX-5. Режим отладки и служебные страницы в продукте
Проверка: агент
Признак: `debug=True`, открытые `/docs`, `/openapi.json`, `/redoc`, страницы состояния без входа.
Не ошибка: включается только переменной окружения стенда, по умолчанию выключено.
Как закрыть: по умолчанию выключено; документация API — за входом или выключена.
Класс: 4, 11

### EX-6. Секрет приходит в браузер
Проверка: агент
Признак: ключ приложения, токен бота, ключ ИИ в ответе маршрута, в HTML, в JS, в теле запроса, который шлёт
браузер. Тот же ключ сервер принимает как доказательство подлинности.
Не ошибка: ключ в браузере — публичный по замыслу и сервер его как пропуск не принимает.
Как закрыть: ключи остаются на сервере; браузеру — своя короткоживущая подпись.
Класс: 4, 5

### EX-7. Данные одного клиента в ответе другому
Проверка: агент
Признак: общий кэш, общая переменная модуля, общий номер сессии между клиентами; история или ссылки клиента
выдаются по признаку, который знает и чужой (телефон, имя).
Не ошибка: ключ кэша содержит клиента; выдача — после подтверждения владельца.
Как закрыть: подтверждение владения до выдачи; кэш по клиенту.
Класс: 1, 4
