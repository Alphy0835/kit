# Ответ владельцу

Открывай, когда пишешь владельцу проекта итог работы, список задач или команду.

Статус: черновик от 16.10.2026, не испытан.

## 1. Начало — что это значит для него, конец — что дальше

Первая фраза — что изменилось для владельца: что теперь работает, что он может сделать, что сломано. Последний
блок — «Что дальше»: его следующие шаги. Задачу к запуску даёшь командой в отдельном блоке кода, одна команда —
один блок, рядом модель и одна фраза о задаче.

## 2. Без внутренних слов

Номер решения, номер задачи, имя файла, переменной или функции — не вместо объяснения. Нужен номер — рядом
фраза, что это: «CB_TASK_303 — счётчик записей в промпте». Решения по номеру не называй вовсе, говори, что
решили.

Как надо: «Бот берёт закреплённые записи, а счётчик на экране считает другую галочку». Как не надо: «Плашка
читает `kb_records.pinned`, а ядро — `kb_selection.pinned_prompt` по D-187».

Почему. 14 поправок — владелец не понял ответ тим лида: номера решений, имена переменных, скрипт без пояснения,
много шагов подряд.

## 3. Список задач — со скрипта

Список открытых задач выдаёшь с вывода `scripts/lead/tasks.py`, а не по памяти. У каждой задачи — о чём она одной
фразой и состояние: ждёт, в работе, сдана, слита. Задача, которая больше не нужна, — с вопросом «отменить?».

Почему. 13 поправок о списке задач: в нём висели устаревшие задачи, сданные числились в работе, у задачи не было
понятно, зачем она.

## 4. Команда — одна и под его оболочку

Владелец выполняет блок целиком. Дай одну команду, которая делает всё, а не пять шагов. Команда — под его
оболочку: в PowerShell 5.1 нет `&&` и `rm -rf`, `sudo` через `ssh` требует `-t`.

Почему. Пять поправок: команда для другой оболочки, `sudo` без терминала.

## 5. Файл — вложением или ссылкой

Файл, который владелец должен открыть, прикладываешь к ответу или даёшь ссылкой, по которой он открывается
щелчком. Путь текстом не годится: его неудобно искать.

## 6. Сроки — из факта

Срок считаешь по прошлым задачам: сколько похожих задач заняло циклов и дней. Часы и недели из головы не
называешь. Свои оценки владелец даёт сам.

Почему. Шесть поправок: оценка вдвое больше факта, коэффициенты без сверки с прошлым.

## Когда не применять

Правило 1 — для ответа в одну строку на вопрос «да или нет». «Что дальше» остаётся.

## Что из этого проверяет скрипт

`scripts/lead/check_reply.py` по тексту ответа: нет блока «Что дальше», команда задачи вне блока кода, путь к
файлу текстом, номер решения. Хук Stop в шапке скила тим лида зовёт его после каждого ответа, с вызова скила до
конца сессии, и возвращает находки модели один раз. Хук пробой не проверен: работает ли он после сжатия
контекста, документация не говорит.

`scripts/lead/tasks.py`: открытые задачи из списка задач со сверкой по веткам — ветка слита, а статус не
закрыт; отчёт есть, а статус «в работе».
