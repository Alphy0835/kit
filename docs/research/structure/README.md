## Что сходится во всех трёх подборках

1. **Границы модулей держит автомат, а не абзац.** Kubernetes, kafka, vscode, cal.com, home-assistant держат правила
   импортов в файле, который читает проверка. Spring Modulith и Shopify гоняют проверку на каждом слиянии. У n8n —
   «храповик»: число старых нарушений записано и расти не может. Это же говорит наш замер.
2. **У модуля один публичный вход и список того, что ему можно импортировать.** Правило пишется со стороны
   вызывающего — «A импортирует только из …», — тогда его можно отдать линтеру.
3. **Решение — отдельная запись, которую не правят.** Замена — новой записью со статусом «заменено». Номер не
   используется повторно. Rust, KEP, PEP, Go, Nygard, MADR, Microsoft, AWS.

## Что сходится в двух подборках

4. Сквозные сценарии: 2–3 пути данных через модули по шагам (arc42 раздел 6, Кратчен, Ubl).
5. Риски и известный долг (Rust Drawbacks, KEP, arc42 раздел 11, ATAM).
6. Конфигурация: значения по умолчанию, образец с заглушками и описание — три разных файла; окружения различаются
   только конфигурацией (Twelve-Factor; grafana, zulip, cal.com).

## Что нашла одна подборка, но бьёт в нашу боль

7. **Миграции — файл-вершина.** Каждая новая миграция правит одну строку в общем файле. Две параллельные получают
   конфликт git, и вторая знает, что перенумеровать. Sentry, mattermost, grafana. У нас 11 столкновений номеров.
8. «Добавляю эндпоинт → какие файлы менять» — дерево в `src/AGENTS.md` у sentry. Шаблоны документации такого раздела не
   знают, а в живых проектах он есть. Наш раздел «Что менять, когда добавляешь» имеет опору.
9. Совместимость: что нельзя сломать у тех, кто уже пользуется (PEP, Go, KEP).
10. Шапка: владелец, дата, «заменяет / заменена» (Rust, KEP, PEP, Go, MADR).
11. Метка «не определено» ставится на месте пробела, а не только в конце (Spec Kit).

## Где подборки расходятся

- **Ось деления.** Стандарты (Фаулер) советуют верхние папки по предмету, слои внутри. Репозитории чаще делают
  наоборот: сверху слой, процесс или приложение, внутри — папка на фичу. Чисто по слою — 5–6 веб-проектов.
  Вывод: шаблону не навязывать одну ось, а требовать строку «ось деления» явно.
- **«Кому можно вызывать».** Подборка стандартов предлагает оставить колонку, подборка репозиториев — заменить на
  «Публичный вход» и «Может импортировать». Второе проверяется линтером, первое — нет.

заказчик потребует документ по ГОСТ), 40 подхарактеристик 25010, KEP и PEP целиком, CODEOWNERS на каждую папку,
диаграммы C4 всех уровней. Тексты arc42 и Diátaxis не копировать (CC BY-SA). Целиком можно взять MADR (MIT или CC0),
шаблон Go (BSD-3), Good Docs (0BSD / MIT-0).
