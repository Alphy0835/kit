Код подпроекта — `SKL`. Заведён 13.10.2026 (D-223).

## Цель

Набор собственных скилов владельца для агентов. Здесь скилы проектируются, пишутся и проверяются.

Наполнение — позже: состав скилов, порядок работы и список источников владелец назовёт сам. Задач пока нет.

## Как выбираются правила

Правила скилов и скринеров опираются на источники: нормативы и стандарты написания кода, руководства ведущих
компаний, правила промптинга от разработчиков моделей. Источники собирает владелец; по его слову поиск ведёт
и тим лид.

Подборки источников лежат в `sources/`:

| Тема | Документ |
|---|---|
| Частые ошибки ИИ при написании кода — что называют крупные компании | `sources/ai-code-mistakes.md` |
| Нормативы и правила написания кода — стандарты, руководства по стилю, правила ревью и готовые наборы правил | `sources/coding-standards.md` |
| Как писать скилы и работать с агентами — руководства, курсы и выступления ведущих компаний | `sources/skills-and-agents.md` |
| Как писать документацию к ИТ-продуктам — ASD-STE100, простой язык, руководства компаний, международные стандарты, ГОСТы, юзер-кейсы и требования | `sources/doc-writing.md` |
| Нейрослоп в тексте — из чего он состоит по замерам и чем его советуют снижать Anthropic и OpenAI | `sources/ai-slop-writing.md` |

## База справочников

Папка `skills/references/writing/`. Знание лежит не в тексте скила, а в отдельных файлах: скил по указателю
`README.md` открывает один-два файла под задачу.

- Файлы `text-*.md` — как писать фразу: упрощённый технический язык по ASD-STE100, простой язык, руководства
  компаний, язык ГОСТа.
- Файлы `doc-*.md` — что в документе и в каком порядке: инструкция, справочник, описание API, вики проекта,
  README, юзер-кейс, требование, ТЗ, руководства по ГОСТу и другие.
- Файлы `check-*.md` — вопросы для проверки готового текста: общие нормы письма и вопросы по видам документов.
- В конце каждого файла — таблица источников с пометкой, что прочитано, а что известно по пересказу.
- Строки с пометкой «предложение тим лида» — не правило, пока владелец их не утвердил.
