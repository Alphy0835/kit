# Группа FI. Загрузка и чтение файлов

Строки: `UploadFile|File\(|multipart|filename|content_type|mimetypes|send_file|FileResponse|StaticFiles|attachment`
Пути: `*upload* *attach* */files/* *media*`

### FI-1. Имя файла от пользователя
Проверка: агент
Признак: файл сохраняется под именем, которое прислал пользователь или чужая система.
Не ошибка: имя задаёт сервер; исходное имя хранится только в базе.
Как закрыть: имя — случайное от сервера.
Класс: 10

### FI-2. Тип файла по расширению или по заявлению клиента
Проверка: агент
Признак: проверка только расширения или `content_type` из запроса; файл потом отдаётся с тем же типом.
Не ошибка: тип проверяется по содержимому, файл отдаётся как вложение.
Как закрыть: проверка по содержимому, список типов, отдача с `Content-Disposition: attachment`.
Класс: 10, 7

### FI-3. Нет предела размера файла
Проверка: агент
Признак: файл читается в память целиком без проверки размера.
Не ошибка: предел на сервере до чтения.
Как закрыть: предел размера, чтение частями.
Класс: 9

### FI-4. Файл отдаётся без проверки прав
Проверка: агент
Признак: маршрут отдачи файла по номеру или имени без сверки владельца; папка загрузок открыта как
статика.
Не ошибка: отдача через маршрут с проверкой права.
Как закрыть: проверка владельца на маршруте отдачи; загрузки — не в папке статики.
Класс: 1, 10

### FI-5. Загруженное лежит там, откуда исполняется
Проверка: агент
Признак: загрузки в папке кода, шаблонов или статики сайта.
Не ошибка: отдельная папка вне кода.
Как закрыть: отдельная папка без исполнения.
Класс: 10
